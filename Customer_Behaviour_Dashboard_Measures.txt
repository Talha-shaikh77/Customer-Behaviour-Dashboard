Create each measure individually in Power BI (Modeling > New measure).

Model relationships are required for slicers to filter the visuals correctly. A typical

// ============================================================
// 1. KPI MEASURES
// ============================================================

Total Sales =
SUM ( 'transaction'[amount] )

Total Orders =
DISTINCTCOUNT ( 'order'[order_id] )

Total Quantity =
SUM ( 'transaction'[quantity] )

Average Rating =
AVERAGE ( 'rating'[rating] )

// Active customers are customers with at least one order in the current filter context.
Active Customers =
DISTINCTCOUNT ( 'order'[customer_id] )

Average Orders per Customer =
DIVIDE ( [Total Orders], [Active Customers], 0 )

// A repeat customer is an active customer with more than one distinct order.
Repeat Customer Count =
VAR CustomerOrderCounts =
    ADDCOLUMNS (
        VALUES ( 'order'[customer_id] ),
        "OrderCount", CALCULATE ( DISTINCTCOUNT ( 'order'[order_id] ) )
    )
RETURN
    COUNTROWS (
        FILTER ( CustomerOrderCounts, [OrderCount] > 1 )
    )

Repeat Customer Rate =
DIVIDE ( [Repeat Customer Count], [Active Customers], 0 )

/*
Formatting for KPI cards:
- Total Sales: currency or whole number, depending on the report's chosen display.
- Total Orders / Total Quantity / Active Customers / Repeat Customer Count: whole number.
- Average Rating / Average Orders per Customer: 2 decimal places.
- Repeat Customer Rate: Percentage, 2 decimal places.
  Do not multiply Repeat Customer Rate by 100 if you apply Percentage formatting.
*/

// ============================================================
// 2. CUSTOMER PURCHASE-FREQUENCY CHART
// ============================================================

/*
Create this as a calculated table (Modeling > New table), not a measure.
It supplies the 1–9 order-frequency categories shown on the chart.
*/

Order Frequency =
GENERATESERIES ( 1, 9, 1 )

/*
Create this as a measure. Put 'Order Frequency'[Value] on the chart's X-axis
and [Customers by Order Frequency] in Values.
The measure counts customers with exactly the selected number of distinct orders.
When a Year slicer is active, frequency is calculated within the current filter context.
*/

Customers by Order Frequency =
VAR SelectedN =
    SELECTEDVALUE ( 'Order Frequency'[Value] )
VAR CustomerOrderCounts =
    ADDCOLUMNS (
        VALUES ( 'order'[customer_id] ),
        "OrderCount", CALCULATE ( DISTINCTCOUNT ( 'order'[order_id] ) )
    )
RETURN
    IF (
        ISBLANK ( SelectedN ),
        BLANK (),
        COUNTROWS (
            FILTER ( CustomerOrderCounts, [OrderCount] = SelectedN )
        )
    )

The following charts can reuse [Total Sales] or [Total Quantity]. The category/age-group

your Power BI model or visual setup requires a different calculation.

- Donut: category = customer age-group field; value = [Total Quantity]
- Bar: category = customer age-group field; value = [Total Sales]
- Stacked column: axis/legend = product category and customer age-group field;
  value = [Total Sales]
- Treemap: group = 'transaction'[payment_mode]; value = [Total Sales]
*/
